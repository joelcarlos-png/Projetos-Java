# Java Projects

A collection of small Java projects developed for learning and practice.

## Structure

- `games/` — a console-based game with battles, exploration, and character progression
- `maquinaDecartao/` — a simple console-based card/account banking system

## Requirements

- Java JDK installed
- IntelliJ IDEA or any Java-compatible editor

## How to Run

### Compile
```powershell
javac games/*.java
javac maquinaDecartao/*.java
