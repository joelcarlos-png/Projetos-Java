# Projetos JAVA

Repositório com pequenos projetos desenvolvidos em Java para consolidaçao do aprendizado em POO.

## Estrutura

- `games/` — jogo em console com batalhas, exploração e evolução de personagem
- `maquinaDecartao/` — sistema simples de cartão/conta bancária em console

## Requisitos

- Java JDK instalado
- IntelliJ IDEA ou outro editor compatível com Java

## Como executar

### Compilar
```powershell
javac games/*.java
javac maquinaDecartao/*.java
